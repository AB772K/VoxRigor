# Changelog

All notable changes to VoxRigor will be documented here.

## Unreleased — Phase 1 core prototype

- Added a lightweight Python package and Typer CLI.
- Added strict offline project manifest validation.
- Added explicit built-in diagnostic test registration and orchestration.
- Added run IDs, UTC timestamps, result statuses and configuration provenance.
- Added JSON and HTML report generation.
- Added machine-readable project, test-result and run-report schemas.
- Added unit tests and GitHub Actions CI configuration.

This prototype does not yet evaluate biometric models, audio attacks, datasets, or target applications.
