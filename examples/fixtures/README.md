# Synthetic score fixtures

These CSV files contain fabricated numeric scores and labels only. They are not voice recordings, not derived from a real speaker, not a trained model output, and not a benchmark dataset. They exist solely to test parsers, metrics, split accounting and report generation.

- `asv_scores.csv`: tiny ASV example with `dev` and `test` splits.
- `pad_scores.csv`: tiny PAD example with three named attack species.

The numbers are deliberately small and are not statistically meaningful. Never cite them as model-performance results.
