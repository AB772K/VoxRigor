# Security Policy

## Project status

VoxRigor is pre-alpha research software. It is not a certified biometric evaluator or a guarantee that a system is secure. The Phase 1 implementation is offline-only and has no target-application network adapter.

## Reporting a vulnerability

Please do not publish credentials, private biometric material, raw voice recordings, or exploitable details involving a third-party system in a public issue.

For a vulnerability in VoxRigor itself, use GitHub's private vulnerability reporting feature where available. Include the affected version/commit, environment, reproduction steps using synthetic or non-sensitive fixtures, expected behavior, observed behavior, and potential impact.

If private reporting is unavailable, open a minimal public issue asking for a private contact route without including sensitive details.

## Safe testing

Only use systems and datasets that you own or are explicitly authorized to assess. Do not upload customer voice recordings, biometric templates, credentials, or private assessment evidence to public issues or pull requests.
