# Phase 0 Closure Checklist

Use this checklist during the Phase 0 review. A box should be checked only when evidence exists.

- [ ] Public project name and repository identity reviewed; no trademark clearance claim.
- [ ] Repository license notice formatting corrected (`Copyright 2026 AB772K`, without square brackets).
- [ ] Project charter reviewed and accepted.
- [ ] Intended users and primary first-release use case validated.
- [ ] Requirements prioritized and testable.
- [ ] Threat model reviewed, including plugin/checkpoint and privacy risks.
- [ ] Authorization/scope model accepted.
- [ ] Competitor and related-work review expanded with current repository activity and licenses.
- [ ] Standards editions/status rechecked against official publishers.
- [ ] Metric definitions and result semantics approved.
- [ ] Dataset use/access terms reviewed from authoritative sources.
- [ ] Model source/checkpoint licenses and provenance reviewed.
- [ ] Initial test catalogue approved.
- [ ] Architecture decisions accepted or amended.
- [ ] First vertical slice and exit criteria frozen.
- [ ] Known risks and unresolved research questions recorded.
